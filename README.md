# The Worst App Idea Ever Pitched

SnoreSync is a dating app that matches insomniacs by the exact pitch of their snoring, then books them a shared hotel room with one pillow, no earplugs, and a kazoo orchestra playing lullabies at 3am

## Run

```sh
node main.ts
```

Writes the one-sentence pitch to `/output/entry.txt`. The program validates the pitch first (1–240 characters, non-blank, single line) and exits non-zero without writing anything if it is invalid.
